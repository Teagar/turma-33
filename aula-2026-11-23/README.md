# Lista de Exercícios Nivelados — Callbacks em JavaScript (Aula de 23/11/2026)

Série de **10 exercícios progressivos** sobre **funções de callback em JavaScript**, elaborada apenas com recursos vistos até a aula de 23/11.

- **Permitido:**
  - funções criadas com `function`, funções anônimas e arrow functions;
  - parâmetros, argumentos e `return`;
  - funções passadas como argumento (callbacks);
  - template strings (crase e `${}`);
  - `console.log()`;
  - operadores aritméticos, incluindo `%` e `**`;
  - laço `for`;
  - arrays com índice e `length`;
  - métodos de string (`toUpperCase`, `toLowerCase`, `trim`, `length`).
- **Sem uso de:**
  - `forEach`, `map`, `filter` e `find`, que são o assunto da próxima aula;
  - `if` ou `switch` para escolher o que fazer no lugar de um callback.

📖 O resumo da aula está em [`aula.md`](aula.md), e todo o código mostrado em aula está em [`aula.js`](aula.js).

## Como usar

- Resolva cada exercício diretamente nos arquivos `ex01.js` até `ex10.js`.
- Para executar um exercício no terminal:
  ```bash
  node aula-2026-11-23/ex01.js
  ```
- O exercício 02 **começa com um erro de propósito**: rode o arquivo antes de corrigir.
- Cada enunciado traz a **saída esperada**. Compare com o que aparece no seu terminal.
- As sugestões de resolução estão na pasta `aula-2026-11-23/gabarito/`. Tente resolver antes de olhar!
