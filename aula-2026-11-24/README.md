# Lista de Exercícios Nivelados — forEach e map em JavaScript (Aula de 24/11/2026)

Série de **10 exercícios progressivos** sobre os métodos de array **`forEach`** e **`map`**, elaborada apenas com recursos vistos até a aula de 24/11.

- **Permitido:**
  - `forEach` e `map`, com o item e o índice no callback;
  - funções criadas com `function`, funções anônimas e arrow functions (com e sem chaves);
  - callbacks, parâmetros, argumentos e `return`;
  - `let` e `const`;
  - template strings (crase e `${}`);
  - `console.log()`;
  - operadores aritméticos, incluindo `**`;
  - laço `for` (só onde o enunciado pedir);
  - arrays com índice, `length` e `push`;
  - métodos de string (`toUpperCase`, `toLowerCase`, `length`).
- **Sem uso de:**
  - `filter` e `find`, que são o assunto da próxima aula;
  - `var`.

📖 O resumo da aula está em [`aula.md`](aula.md), e todo o código mostrado em aula está em [`aula.js`](aula.js).

## Como usar

- Resolva cada exercício diretamente nos arquivos `ex01.js` até `ex10.js`.
- Para executar um exercício no terminal:
  ```bash
  node aula-2026-11-24/ex01.js
  ```
- Os exercícios 02 e 04 **começam com um erro de propósito**: rode o arquivo antes de corrigir.
- Cada enunciado traz a **saída esperada**. Compare com o que aparece no seu terminal.
- As sugestões de resolução estão na pasta `aula-2026-11-24/gabarito/`. Tente resolver antes de olhar!
